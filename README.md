# Task Management REST API

## Overview
A robust, scalable REST API for managing tasks, built with Python and Flask. This project demonstrates modern DevOps practices including Agile planning, automated testing, containerization, and CI/CD pipelines.

## Project Status
Currently in **Sprint 0** (Planning & Setup phase).

## Quick Start
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run tests: `pytest`
4. Start application: `python app/routes.py` (once implemented)
